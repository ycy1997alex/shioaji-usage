永豐金 API 用量評估工具 — 使用說明書

適用版本：v20260712（2026-07-12）

這是一個查詢「永豐金證券 Shioaji API 今日用量」的小工具，讓您隨時查看：

  • 今日流量：已用多少、每日上限多少、還剩多少（永豐金每天重置流量額度）。
  • 連線數：目前這組憑證佔用的 API 連線數（上限 5 條）。

您只需要兩個東西：本說明書與 執行檔（.exe）。免安裝，點兩下即可使用。

快速開始

最常見的用法：開啟程式 → 按「查詢」→ 看今日用量。第一次使用需要先準備一組 API 金鑰。

第一次使用前：申請 API 金鑰

  1. 您需要有永豐金證券的證券帳戶。
  2. 到永豐金 API 金鑰申請頁：www.sinotrade.com.tw/newweb/PythonAPIKey/（登入後依指示申請）。
  3. 申請完成會得到一組 API Key 與 Secret Key。Secret Key 只在申請當下顯示一次，請妥善保存。

開始查詢

  1. 點兩下執行檔開啟程式（第一次啟動需解壓縮，等候數秒屬正常）。
  2. 視窗會出現在螢幕左上方區域；第一次使用畫面顯示「尚無查詢紀錄」。
  3. 按下方藍色「查詢」按鈕。第一次會跳出金鑰設定視窗：
    • 貼上您的 API Key 與 Secret Key（Secret Key 會以星號顯示）。
    • 選擇帳戶模式：一般請選 🟢 真實帳戶；若您申請的是模擬環境金鑰才選 🧪 模擬帳戶。
    • 按「確認」。
  4. 登入與查詢通常數秒內完成，儀表板隨即顯示最新用量，左上角狀態變成「● 已登入」。
金鑰輸入一次即可：程式會加密保存在您這台電腦、這個 Windows 帳戶底下，之後按「查詢」不必再輸入。

結果解讀

畫面項目意義與正常範圍
左上狀態燈綠色「已登入」＝目前已連上永豐金、數字為即時查詢結果；灰色「未連線」＝畫面顯示的是上次的舊紀錄（重開程式時的預設狀態），按「查詢」才會更新。
圓形儀表（%）今日流量已使用的百分比。0–79% 為藍色屬正常；達 80% 變紅色，代表流量即將用完，建議減少大量資料查詢或等隔日重置。
已用流量 / 每日上限 / 剩餘流量今日的實際數值。額度由永豐金每日重置，故「已用」會在重置後歸零、「剩餘」回到接近上限。
目前連線數 X / 5這組憑證目前佔用的 API 連線數，上限 5 條。本工具查詢後會保持 1 條連線直到您關閉視窗。若數字比預期大，通常是您其他程式也用了同一組金鑰。
上次查詢：…最近一次成功查詢的時間與當時的帳戶模式（真實／模擬）。關掉程式再開，仍會先顯示這筆，方便您回顧。

使用建議與限制

  • 更換金鑰或帳戶模式：按「金鑰設定」修改後按「確認」。若當時已登入，程式會自動登出，下次按「查詢」即以新設定重新登入。
  • 真實與模擬帳戶分開計算：兩種模式的用量額度互不相干，查到的數字不能互相比較。
  • 連線會被佔用：查詢後本工具保留 1 條連線直到您關閉視窗。若您同時要跑會大量連線的交易程式，記得關掉本工具以釋放連線。
  • 資料只留在本機：程式會在執行檔旁自動建立一個隱藏資料夾，存放您的設定與上次查詢紀錄；金鑰以 Windows 帳戶綁定加密保存，別人拿走檔案也無法解讀。
  • 換電腦或換 Windows 帳戶要重輸金鑰：因為加密綁定這台電腦與這個 Windows 使用者，換環境後第一次查詢需重新輸入金鑰，屬正常現象。
  • 本工具不能做什麼：它只查用量，不下單、不看報價、不做任何交易；數字僅供參考，一切以永豐金官方系統為準。

常見問題與疑難排解

狀況 / 訊息處理方式
「API Key 或 Secret Key 不正確」按「金鑰設定」重新貼上金鑰（注意前後不要多空白）。若 Secret Key 遺失，請到永豐金申請頁重新申請一組。
「連線被拒絕」「TCP 連線失敗」「授權逾時」多半是網路環境（公司防火牆、代理、VPN、資安軟體）擋住對外連線，不一定是金鑰錯。可改用手機熱點交叉測試，或請 IT 放行本程式。
第一次開啟很慢，或防毒軟體警示單一執行檔第一次啟動需解壓縮，等幾秒屬正常；部分防毒對這類程式較敏感，將檔案加入允許清單即可。
流量什麼時候歸零？額度由永豐金每日重置；確切重置時間以永豐金官方公告為準。
連線數看起來比預期多同一組金鑰在其他程式（含您自己的交易程式）的連線也會計入。關閉本工具會釋放它佔用的那 1 條。
想清除所有資料關閉程式後，刪除執行檔旁那個隱藏資料夾即可（之後再開會回到「尚無查詢紀錄」，需重新輸入金鑰）。
本工具僅供查詢參考，用量數字以永豐金證券官方系統為準。使用本工具所產生之任何結果，作者不負擔保責任。API 金鑰屬個人機密，請勿提供給他人。
